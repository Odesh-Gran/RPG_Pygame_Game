# 🏰 Убежище в замке — RPG игра на Python

RPG-игра с боевой системой, крафтом, торговлей, квестами и системой сохранений.

## 🎮 Особенности
- Полноценная боевая система (атака, защита, навыки)
- Система инвентаря и экипировки (оружие, броня, амулеты)
- Крафт предметов из ресурсов
- Торговля с NPC
- Система квестов (основные и ежедневные)
- Сохранение и загрузка игры (5 слотов)
- Карта мира с открытием локаций
- Анимации и видео-переходы
- Пояс с зельями для быстрого использования в бою

## 🛠️ Технологии
- Python 3.14
- Pygame
- Объектно-ориентированная архитектура
