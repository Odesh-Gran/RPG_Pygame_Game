# 🏰 Убежище в замке

RPG-игра на Python (Pygame): 12 локаций, боевая система, крафт, торговля, квесты, навыки и синхронизация достижений с API.

**Связанные проекты:**
- 🚀 [Game API](https://github.com/Odesh-Gran/Game-API) — backend (FastAPI)
- 🌐 [Game Website](https://github.com/Odesh-Gran/Game-Website) — сайт

---

## 📋 О проекте

Полноценная 2D-RPG с открытым миром. Игрок исследует замок и окрестности, сражается с врагами, крафтит предметы, торгует с NPC, выполняет квесты и прокачивает навыки.

При запуске игра подключается к [Game API](https://github.com/Odesh-Gran/Game-API) через JWT-аутентификацию и синхронизирует достижения игрока.

---

## 🛠 Стек

- Python 3.12
- Pygame
- pyvidplayer2 (видео-переходы)
- requests (API-запросы)
- JSON (сохранения, данные)

---

## ✨ Возможности

### Геймплей
- ✅ **12 уникальных локаций** (замок, сад, пруд, библиотека, темница, лес, склеп)
- ✅ **Боевая система**: кровотечение, оглушение, вампиризм, ярость, контратака
- ✅ **Крафт** (верстак) — оружие, броня, еда, материалы
- ✅ **Торговля** с NPC (покупка/продажа, советы торговца)
- ✅ **Квесты**: сюжетные + ежедневные
- ✅ **Навыки**: профессиональные (кулинария, алхимия, кузнечное дело) и боевые (3 ветки)
- ✅ **Данжи**: Зачарованный лес, Древний склеп (с боссами)

### Интерфейс
- ✅ Инвентарь, экипировка (оружие, броня, амулет), пояс с зельями (5 слотов)
- ✅ Карта мира с открытием локаций через барьеры
- ✅ Лог событий и боевой лог
- ✅ Музыка для каждой локации
- ✅ Видео-переходы между локациями

### Сохранения и API
- ✅ **5 слотов сохранений** (JSON)
- ✅ **Синхронизация достижений** с [Game API](https://github.com/Odesh-Gran/Game-API) (JWT)
- ✅ **Авто-логин** через `token.json`

## 🚀 Установка и запуск

### 1. Клонировать репозиторий

```bash
git clone https://github.com/Odesh-Gran/RPG_Pygame_Game.git
cd RPG_Pygame_Game
```

### 2. Установить зависимости

```bash
pip install pygame pyvidplayer2 requests
```

### 3. Запустить игру

```bash
python gui_game.py
```

При первом запуске откроется **экран логина**.  
Зарегистрируйся или войди через [Game API](https://api.castle-survival.ru/docs).

## 🎮 Управление

- **WASD / стрелки** — движение в данжах
- **ЛКМ** — выбор, действия, бой
- **F11** — полноэкранный режим
- **ESC** — выход из меню/диалога
